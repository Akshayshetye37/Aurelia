# AURELIA Hotel PMS

Android WebView wrapper for the supplied hotel PMS HTML. GitHub Actions builds a debug APK from the source.

## Build
Open the Actions tab and run **Build AURELIA Android APK**. Download the `aurelia-debug-apk` artifact from a successful run.

This wrapper does not provide a backend, cloud synchronization, secure multi-user authentication, or production-grade data persistence. Test all operational workflows before using with live hotel data.
